One original one-line dad joke, written by a tiny Python program for the
[make.fun](https://make.fun) bounty **The One-Liner Groan-Off**.

The joke:

> I tried to start a band called 999 Megabytes. We never got a gig.

Why it works: a band called "999 Megabytes" is one megabyte short of a
gigabyte — so of course it never got a *gig*. Setup, twist and punchline
all land inside a single 65-character line, easy to say out loud and
easy to pass on.

## How to run

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (creating `/output` if needed)
with mode `0644`. The program enforces the bounty limits itself: it fails
loudly if the joke is not a single non-blank line of at most 140 characters.
